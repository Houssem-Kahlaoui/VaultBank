# 🏦 VaultBank

Application bancaire full-stack — API REST Flask + MySQL, frontend Jinja2.

## Stack

- **Backend** : Flask 3, SQLAlchemy, MySQL, JWT
- **Frontend** : Flask, Jinja2, HTML/CSS/JS

## Structure
VaultBank/
├── backend/ → API REST (port 5000)
└── frontend/ → Interface utilisateur (port 3000)

text

## Lancer le projet

### Backend

```bash
cd backend
venv\Scripts\activate        # Windows
pip install -r requirements.txt
python run.py
→ API : http://localhost:5000

Frontend
bash
cd frontend
python app.py
→ Interface : http://localhost:3000

```
